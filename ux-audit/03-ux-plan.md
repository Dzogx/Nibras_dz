# خطة UX — «مكتب الأستاذ» (بدون تغيير المعمارية)

## المبدأ الموجه
الأستاذ الجزائري يعمل من مكتبه: ورق منظم، خطوة واحدة واضحة، لا جدران من البطاقات. الصفحة لا تسأل «ماذا تريد؟» بل تجيب «ماذا أفعل الآن؟». كل صفحة: عنوان واضح + سياق تربوي (المستوى، القسم، الوضعية الحالية) + إجراء رئيسي واحد + تسلسل مرئي واضح.

## نظام التصميم الجديد (نظام «الدفتر»)

| العنصر | قبل | بعد |
|---|---|---|
| الخلفية | رمل فاتح + توهجات | ورق أبيض دافئ (#fffdfb) بخطوط دفاتر خفيفة جداً |
| البطاقات | ظلال عميقة + حدود ملونة | حدود 1px محايدة، زوايا 8px، بلا ظلال إلا للحوارات |
| الخط الأساسي | Cairo 14px | Cairo 16px للنصوص، عناوين أكبر وأقرب |
| الأزرار | شريط مزدحم متساوٍ | إجراء رئيسي بارز واحد + ثانويات في «المزيد» |
| الخطوات | بطاقات متفرقة | مسار مرقّم أفقي (1 حضّر 2 حزمة 3 نفّذ 4 قوّم) |
| الألوان | بنفسجي/نحاسي/ذهبي كلها مرة | حبر داكن للأساس، ذهبي فقط للإجراء التالي، أحمر للتقويم |

## المكونات المشتركة الجديدة (تُضاف ولا تُحذف القديمة تدريجياً)
- `OfficeHeader`: ترويسة صفحة موحدة — مسار Breadcrumb تربوي + عنوان + إجراء رئيسي.
- `StepTrack`: مسار خطوات مرقّم مشترك.
- `nibras-office-*` فئات CSS في index.css.
- إعادة هيكلة الشريط الجانبي: تسميات أبسط (اليوم، الأسبوع، المخططات، التقويم، النتائج، المكتبة، دفتر التجارب، الإعدادات) مع أيقونة وحيدة لكل بند.

## الصفحات المستهدفة بالترتيب
1. DashboardLayout (هيكل + تنقل).
2. Dashboard (صفحة اليوم — جواب فوري + مسار الحصة).
3. AnnualPlanDetail (المخطط/المقطع + الوضعية الحالية + حزمة الحصة).
4. LessonDetail (المذكرة — تسلسل بناء → معاينة → طباعة → تنفيذ).
5. Assessment + ResourceDetail + ContentLibrary.
6. Results/StudentResults/Gradebook + Competencies + ExperimentLog + Inspector.
7. الهاتف: تحقق 375px لكل المسارات.

## قواعد صارمة
- لا تغيير schema ولا routers بشكل وظيفي (فقط UI).
- لا حذف ميزات؛ إعادة تنظيم فقط.
- الوثائق المطبوعة تبقى على حالتها (رسمية محايدة).
- كل تغيير صغير checkpoint.
