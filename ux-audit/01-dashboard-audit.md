# تدقيق UX — صفحة اليوم (Dashboard)

## البنية الحالية (client/src/pages/Dashboard.tsx، ~1191 سطراً)

1. ترويسة ترحيب hero (شعار + «مرحباً» + سنة) مع شريط مسار عمل (اليوم → المذكرة → التنفيذ → المتابعة).
2. بطاقة «مسار حصتك الآن» (Card داكنة بتدرج): حصة اليوم/القسم/المادة/المقطع/الوضعية + زر رئيسي «حضّر/افتح مذكرة الحصة» + قائمة «المزيد» (سجّل نتيجة، نشاط/مورد، وضعية إدماجية، تقويم، نتائج) + صندوق إرشاد للحصة المفتوحة + «تغيير القسم».
3. حالات: جدول ناقص، تحميل، لا قسم، لا وضعية معلقة (كلها توجه لـ /season-setup أو /annual-plans).
4. بطاقة «جاهزية الأسبوع القادم» (أسبوعية AI): بطاقات لكل قسم فيها: الوضعية التالية (زر)، استراتيجية التسيير، عدد الحصص بلا مذكرات.
5. Dialog «إنهاء الحصة» (4 حالات: مكتملة/جزئي/مؤجلة/ملغاة + ملاحظة) و Dialog «اقتراح موعد بديل» للحصص المعوضة.
6. (بقية الملف بعد س790): محتمل أقسام إضافية: متابعة أوسع، أين وصلت في الخطة، استراتيجية التسيير، إجراءات سريعة.

## الاحتكاكات المرصودة

- الإجراءان الأهم (حزمة الحصة، سجّل النتيجة) مدفونان: أحدهما زر والآخر داخل قائمة «المزيد» — لا يظهر مسار «حضّر ← أنشئ الحزمة ← نفذ ← قوّم».
- لا يوجد مفهوم «حزمة الحصة» (مذكرة+بطاقة+ورقة عمل+تقويم) رغم أن البنية التحتية موجودة جزئياً (lesson-generator supports contentType، activity cards).
- «استراتيجية التسيير» تظهر في بطاقة الأسبوع وتفتح dialog داخلي (strategySituationId + PrintHtml مدمج في الصفحة — كود ضخم ~80 سطر HTML مضمن).
- كثافة معلومات عالية: بطاقات متعددة، Dialogs ثقيلة، حالة كل قسم تُخفى خلف list.
- الترحيب hero يستخدم صورة خارجية nibras-bilingual-lockup_8f848dcc.png + فئات nibras-glow-pattern/nibras-orientation-hero.

## أهداف إعادة التصميم لهذه الصفحة

- جواب فوري: «ماذا أفعل الآن؟» — الحصة القادمة + مسار خطوة بخطوة (حضّر الحصة ← أنشئ الحزمة ← نفّذ ← قوّم).
- دمج «استراتيجية التسيير» كخطوة في مسار الحصة لا كبطاقة مستقلة.
- تحويل قائمة «المزيد» إلى خطوات مقترحة سياقية بترتيب تربوي (حزمة → تنفيذ → تقويم → علاج).
- تقليل البطاقات: مساحات بيضاء، طباعة قوية، تسلسل رأسي واحد.
