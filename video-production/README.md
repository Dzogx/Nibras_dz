# فيديو شرح جولة الخبير

هذه النسخة البديلة لا تستخدم بيانات الأستاذ أو التلاميذ، ولا تتصل بواجهة التطبيق أو قاعدة البيانات. تُجمع من أربع صور مرجعية آمنة، وأربعة مقاطع تعليق عربي، وموسيقى أصلية هادئة.

## البناء

```bash
node build-expert-tour-video.mjs
```

الملف النهائي: `output/nibras-expert-tour-ar.mp4`.

تم اختيار هذا المسار بعد بلوغ حد اللقطات المولدة، حتى يتوفر فيديو آمن يمكن مشاركته مع الخبير فوراً.
